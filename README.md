# Personal Finance Analytics | Excel, Power BI & SQL

## Project Overview

This project analyzes personal finance data using Microsoft Excel, Power BI, and MySQL to gain insight into income, expenses, savings, and spending patterns.

The project includes interactive dashboards, financial visualizations, and SQL queries to identify spending trends, evaluate financial performance, and demonstrate data quality practices.

## Data Quality & Missing Data

This project uses **illustrative examples** of financial performances. This project intentionally simulates a **real-world missing-data scenario.** May's financial records are represented as `NULL` values in SQL to simulate missing data from actual zero values.

The analysis covers **11 months of available financial data**, rather than a complete 12-month year. May is excluded from financial totals and averages where appropriate.

## SQL Development Process

This SQL script documents the development process of this project, from database setup and table creation to data insertion, corrections, data validation, and financial analysis.

Some SQL statements are intentionally commented out to preserve the development workflow and document the steps used to build and refine the database. These include:

- **Database and table creation.**

- **Sample financial data insertion.**

- **Data corrections and updates.**

- **Data validation queries.**

- **Final analytical queries used to investigate financial trends.**

This approach provides visibility into the steps taken throughout the project rather than showing only the final results.

## Tools Used

- **Microsoft Excel:** Interactive financial dashboards, charts, pivot tables, and data analysis.

- **Power BI:** Interactive reports, financial KPIs, and spending visualizations.

- **MySQL:** Relational database design, SQL queries, data validation, and missing-data analysis.

## Project Structure

- **Excel**—Financial Dashboard and Workbook

- **Power BI**—Financial Overview and Spending Analysis reports

- **SQL**—Database setup, data validation, and financial analysis queries

## Project Objective

To demonstrate essential skills in data analysis, dashboard development, SQL queries, data validation, and responsible handling of missing data.
